# 主线重构：面向生物序列的 Jev 式决策模型

日期：2026-09-24。模型与仓库名称仍为 **Laya-Bio**；论文标题改为 **Jev-Style Decision Models for Biological Sequences**。

## 一句话主张

将生物序列、自然语言问题和候选标签输入同一个共享决策模型，直接输出候选概率和确定的标签身份，在多任务接口中省去自由生成答案再解析的步骤。

## 为什么这样改

旧稿以候选评分、BPE 和可靠性并列展开，读者不容易首先看见问题。新稿先解释 Jev 式接口为何与许多生物分类任务相契合，再讨论准确率、输出合法性、任务复用和决策稳定性。BPE 保留为输入表示消融，不再承担主贡献。

官方名称为 **Jev**，不是 JVE。[TypeSafe 的官方介绍](https://typesafe.ai/blog/introducing-system-one-models-and-jev)和[接口文档](https://docs.typesafe.ai/introduction)用于命名和动机；本文不使用官方 Jev 权重，也不把产品的效率／校准表述当作本研究的生物学证据。

## 关键表达

| 想表达的核心 | 本文采用的可检验表述 |
|---|---|
| 生物任务大多就是作判断 | 许多下游生物预测是分类或有限候选决策；不把回归、生成和结构重建都归为分类 |
| 传统分类头一题一个模型 | 固定头绑定标签坐标；可以共享编码器，因此必须比较共享编码器多头 |
| 语言模型标签会漂移 | 自由生成可能出现别名、额外解释、含混或集合外标签，发生率需要实测 |
| Jev 保证标签不漂移 | 索引查表保证输出属于给定集合且标签身份明确；不能保证选对或对标签措辞不敏感 |
| 一个模型解决所有问题 | 当前是两个已训练任务的共享模型；同模态多任务、改写和新任务测试后才能扩大主张 |

输出错误要分开：严格输出契约违规、无法唯一映射到规范标签，以及合法但错误的生物类别。别名可单独报告，不应掩盖严格格式违规；合法率也不能取代 Accuracy/F1。

## 已有证据如何服务新主线

- 一份 candidate checkpoint 联合处理 DNA 启动子检测和蛋白结构七分类；raw test Accuracy 为 91.10%/59.97%。
- 共同使用 BPE 时，candidate 相对本版 B1 的 Accuracy 增益为 1.40/7.91 个百分点。这不是“语义候选”单一因素的严格因果证明。
- B1 自己也是共享编码器、多任务输出头。候选方法的区别是用共享评分器读取输入标签，而不是首创共享模型。
- text-only 与序列干预支持模型使用序列信息。
- BPE 蛋白候选重排改变 9.04% 预测，说明即使输出一直在集合里，决策仍可能随顺序变化。
- 旧测试全部保留；本轮没有新训练、新推理、生成式基线结果或任务迁移结果。

## 决定性补充实验

1. **核心对照：**相同生成 checkpoint 的自由生成、受约束生成和完整候选似然评分，对比 Laya-Bio、共享编码器多头及单任务模型。受约束生成和固定头也可以零集合外输出，因此主贡献必须体现在有用的预测／复用／成本组合上。
2. **通用接口：**优先 12 项、扩展 12 个视图，对应 Choice/Score/Noul，并加入同模态、多标签及双序列任务；另训移除定位或稳定性监督的 leave-one-task-out 模型。数据准入及跨任务同源污染需先审核。
3. **语义与稳定：**问题改写、核验过的标签别名／描述、候选重排和随机 ID，分别报告合法率与正确率。
4. **实际效率：**同硬件端到端延迟、吞吐、显存和概率质量；不把训练时间或 token 减少当作推理速度证据。

完整设置、模型版本、任务候选、预算和停止条件见[实验计划](../refine-logs/EXPERIMENT_PLAN.md)，状态见[执行表](../refine-logs/EXPERIMENT_TRACKER.md)。计划优先采用 Qwen3-0.6B 作为现有单卡可处理的小型序列—语言 SFT 对照，明确其与 LLaMA-Gene/ChatNT 的区别；不靠一个不受约束的弱基线支撑结论。

## 文稿改动与证据边界

英文标题、摘要、引言、相关工作、方法输入输出契约、实验组织、结果导读、局限与结论已改写。中文稿和 README 同步。论文新增的 Appendix B 为明确标记的后续设计；不存在把它写成已完成实验的情况。新增引用包括 TAPE、DeepLoc 2.0、DeepGOZero、官方 Jev 技术公告与 [PICARD](https://aclanthology.org/2021.emnlp-main.779/) 受约束解码论文。

## 扩展任务与数据核查

完整[任务目录](biological_decision_task_catalog.md)区分来源核实、数据审计与训练准入。Score 用于有序水平，连续值适配必须保留原尺度误差与回归对照；多标签用逐标签 Noul，不能把单标签定位伪装成多标签。已发现上游 DNA 池含旧 test、跨任务相同序列，以及 DNA–protein 配对的确定性翻译捷径；这些都已进入准入条件。六任务 pilot 后才规划 12 项联合实验，当前没有新增模型结果。
