# 剪接与 GFP：单任务对照和数据诊断

日期：2026-09-24。**状态：五次训练、CPU 对照和联合模型训练子集评估均已完成。** 范围：上一轮六任务开发实验的后续诊断，单 seed，沿用每任务 1,024 train / 128 dev。所有结果属于开发阶段，未运行新的测试集评估。

## 预先固定的对照

- 剪接与 GFP 各训练候选评分器、共享多头一次，共四次；从原始 Laya 权重开始，不续训联合模型。保留多头模型全部 head 的初始化顺序，仅更新目标任务。
- 从原来的 576 步联合采样计划中抽取目标任务的 96 步，严格复用每批样本及对应学习率。因此每个任务都是三遍、3,072 次生物样本曝光，候选排列、batch、优化器、损失不变。调度器逐批核验样本哈希和学习率，并对比训练前预测。
- 这是**任务曝光匹配**，不是总计算量匹配。联合模型还有其他五个任务的更新；共享参数的 Adam 状态、dropout 随机轨迹也不同。单 seed、少量 dev 样本不能完成严格的负迁移因果判断。
- 训练诊断固定使用已有 hash 排序下前 128 个训练样本，按规范候选顺序评估；它们不参与额外更新。联合 checkpoint 也在相同子集上评估。
- CPU 对照预先固定：按位置 one-hot 的逻辑回归 `C=1, max_iter=2000`；GFP 岭回归 `alpha=10, solver=lsqr`。不按 dev 选择超参数。GFP 有 236/237 aa 两种长度，先比对到仅用训练集生成的共识序列，再编码位置；本次没有未编码的插入残基。此修正发生在首次成功得到 GFP CPU 结果之前。

## 输入与标签检查

两任务逐行与源文件匹配，序列、数字标签/连续值不一致数为 0；候选标签排列错误、marker 数错误、UNK token 均为 0。完整输入范围：剪接 202–231 tokens，GFP 238–244 tokens，均低于 1,024 上限。因此没有发现截断或未知 token 导致的输入丢失。

剪接训练类别计数为 `[221, 201, 602]`，dev 为 `[21, 34, 73]`。联合候选评分器在 dev 上预测计数为 `[0, 4, 124]`，多头为 `[0, 0, 128]`，确有多数类塌缩。

GFP 训练五个 bin 基本均衡，dev 计数为 `[36, 23, 29, 19, 21]`。联合评分器输出连续值的标准差仅 **0.00220**，多头标量预测为 **0.00290**，而真实 dev 值标准差为 **0.86709**。两者预测都接近常数。已知正确 bin 后使用训练 anchors 的 oracle MAE 是 **0.19926**；这是使用真实 dev bin 的量化参考，不能当作可部署基线，也不是概率加权连续解码的严格误差下界。当前约 0.62 的误差不能仅归因于五档量化。由于期望值解码与标量 MSE 更接近均值目标，同时检查训练均值常数：dev RMSE 为 **0.87504**，联合评分器/多头分别 **0.87661/0.87763**，同样未超过这个简单对照。

## 剪接类别名称的冲突与版本修正

历史构建器把上游数字标签映射为 `0=Non-splice, 1=Acceptor, 2=Donor`。此前与旧本地文本标签一致的检查只验证了内部一致性，**不能独立证明生物学语义正确**。

原始 [SpliceFinder 推理代码](https://github.com/deepomicslab/SpliceFinder/blob/master/SpliceFinder_sourcecode/test/test_Cla.py) 将 class 0 送入 acceptor 模型、class 1 送入 donor 模型，class 2 是非剪接背景；[标签生成代码](https://github.com/deepomicslab/SpliceFinder/blob/master/iteration_process/generate_seq/generate.py) 也以 2 初始化背景。训练集中心 motif 与这一约定一致：class 0 的 **221/221** 序列在零起始位置 198–199 是 AG；class 1 的 **200/201** 序列在位置 200–201 是 GT。AG/GT 是 acceptor/donor 的典型信号，但也可能出现在负例中，不能据此逐条重标注。[SpliceFinder 原论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC6933889/)

据此创建 `pilot_data_v2_splice_names`：只把候选名称改为 `['Acceptor site', 'Donor site', 'Non-splice site']`，不变更任何数字标签、序列、ID、分组和划分。新构建器采用这一约定，历史数据和训练记录保留。由于 [dnagpt 数据卡](https://huggingface.co/datasets/dnagpt/dna_splice_site_prediction) 未给出明确的标签定义及完整生成链，这是一项由原始代码和本地训练 motif 支持的修正，尚不能宣称所有上游谱系已经核实。

另补一个同预算的候选评分器单任务实验，只改变这些名称。多头模型不读取候选文本，故这一名称修正不改变它的输入或监督，无需为文字改动重复训练多头。旧剪接结果仅保留为数字类别的历史工程对照，暂停将它们解释为正确命名的生物学决策结果。

| 任务 | 指标 | 常数基线 | 联合评分器 | 联合多头 | 位置特征模型 |
|---|---|---:|---:|---:|---:|
| 剪接 | Accuracy ↑ | 57.03% | 57.03% | 57.03% | 60.94% |
| 剪接 | Macro-F1 ↑ | 0.2421 | 0.2754 | 0.2421 | 0.5585 |
| GFP | MAE ↓ | 0.5623（训练中位数） | 0.6242 | 0.6225（标量头） | 0.4930 |

逻辑回归训练准确率为 100%，dev 60.94%，有明显泛化差距。GFP 岭回归训练 MAE 0.3501、dev 0.4930，说明当前样本含有可学习的位置/变异信号；不能将神经模型表现差归因为数据完全无信号。位置模型提供了任务特定归纳偏置，不能把差距完全归因于参数规模或多任务干扰。

## 神经对照执行状态

四次原始命名单任务对照已经完成，均为 96 次实际参数更新、3,072 次目标任务样本曝光。训练前概率与对应联合实验一致（最大误差 0），所有批次及学习率复核一致。

| 任务 / 输出 | 指标 | 联合训练 | 单任务训练 |
|---|---|---:|---:|
| 剪接 / 候选评分器（历史名称） | Accuracy ↑ | 57.03% | 57.03% |
| 剪接 / 多头 | Accuracy ↑ | 57.03% | 57.03% |
| GFP / 候选评分器 | MAE ↓ | 0.6242 | 0.6193 |
| GFP / 候选评分器 | Spearman ↑ | 0.1132 | 0.1462 |
| GFP / 多头标量输出 | MAE ↓ | 0.6225 | 0.6107 |
| GFP / 多头标量输出 | Spearman ↑ | -0.0205 | -0.1305 |

单任务没有消除剪接多数类塌缩；GFP 的 MAE 小幅变化，但排序仍弱，候选评分器与标量头的 RMSE 分别为 0.87765 / 0.88222，仍未超过训练均值常数的 0.87504。这一预算下没有看到“取消其他任务后明显恢复”的现象，不能把失败主要归因于多任务负迁移，也不能据此排除其他预算或 seed 下存在负迁移。

只修正候选名称的单任务评分器已经完成：dev Accuracy **57.03%**、Macro-F1 **0.2421**；固定训练子集 Accuracy **53.13%**，仍为多数类预测。名称修正是必要的数据语义修复，但不足以消除当前训练预算下的塌缩。

这五次实验中，剪接的固定训练子集类别多数占比为 53.13%，单任务模型和名称修正模型都停在这个水平；GFP 单任务评分器在固定训练子集的五档准确率仅 18.75%，CE 1.6083，接近均匀五类的 `ln(5)=1.6094`。虽然部分训练样本的连续预测存在弱排序信号，输出幅度仍不足。证据更支持当前表示/优化组合存在拟合不足，而不是仅在 dev 上过拟合失效。

启动时第一次冻结代码快照遗漏 `laya_metrics.py`，进程在导入阶段退出，未加载模型或更新参数；补齐依赖后以新目录 `single_task_diagnostics_v2` 重启，保留失败日志。该失败与模型训练无关。

联合模型在相同 128 个训练样本上的结果也显示拟合不足：剪接候选评分器 Accuracy 为 54.69%、多头为 53.13%；GFP 候选评分器五档 Accuracy 为 16.41%、CE 为 1.6100，接近均匀预测。GFP 训练子集连续值 MAE：联合评分器 0.6655、单任务评分器 0.6589；联合多头标量 0.6636、单任务标量 0.6498。单任务评分器预测标准差为 0.00632、多头标量为 0.00166，仍明显小于真实 dev 标准差。

整个神经诊断队列运行于 **06:49–07:05 UTC**；五次纯训练合计 **12.19 分钟**，包含加载、重载和额外训练子集评估的总跨度约 **15.54 分钟**。五个 checkpoint 哈希均与记录一致，全部 480 条训练记录的损失与梯度有限，重载概率最大差均为 0，名称修正前后也通过了逐批样本和学习率一致性检查。成功队列日志无 OOM 或异常栈。

## 下一步的实验优先级

1. 先做固定小训练子集的拟合能力检查（例如 32 个样本），观察 Choice 与 Score 能否学到非平凡训练预测；这项检查不需要 dev 调参。若连小子集也拟合不了，优先检查表示、读出和优化设置。
2. GFP 保留位置岭回归作为必要对照，后续比较残基级或蛋白序列表示；同时区分 Score 分类学习、连续值解码与标量损失的影响。
3. 剪接使用修正名称的新版本继续研究，并保留完整上游谱系核验这一数据准入要求。扩大任务数前，应先摆脱训练集多数类塌缩。

以上是由本轮结果形成的后续计划，尚未启动新的调参或扩大训练。独立多标签阈值校准仍需单独留出的校准数据。
