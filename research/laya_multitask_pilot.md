# 六任务联合训练 pilot

日期：2026-09-24。状态：两个 100 步 pilot 已完成；六任务子集三遍曝光训练也已完成。该轮是工程性可行性实验，不能代替新的同源隔离测试或正式三 seed 比较。

> 后续审计发现剪接候选名称与 SpliceFinder 编码存在冲突；本文的历史剪接数字类别结果保留，生物学名称解释暂停。修正与单任务对照见 [诊断报告](laya_task_diagnostics.md)。

## 问题与训练设置

目标是验证同一个 checkpoint 能否联合处理 Choice、Score、Noul、双序列输入和多标签面板。使用原始 Laya 初始化，不从已经看过旧训练任务的模型继续训练。共享评分器与共享编码器多头使用同一六任务数据、相同生物样本曝光顺序、seed 20260924、100 次优化更新、有效 batch 32、AdamW 初始学习率 2e-5、BF16；没有额外 CPT。

| 任务 | 接口 | 训练 / dev 生物样本 |
|---|---|---|
| 启动子 | Noul | 1,024 / 128 |
| 剪接位点类型 | Choice，3 类 | 1,024 / 128 |
| 蛋白结构类别 | Choice，7 类 | 1,024 / 128 |
| 双蛋白同源关系 | Noul，双序列 | 1,024 / 128 |
| GFP log fluorescence | Score，5 个训练集分位等级 | 1,024 / 128 |
| DeepLoc 多标签定位 | 10 个 Noul 边际概率 | 1,024 / 128 |

每份数据共 6,144 train / 768 dev 生物样本。候选方法展开为 15,360 / 1,920 个决策条目。多标签每个蛋白的十项损失取平均，六个任务按训练步均衡轮转。100 步只是管线 pilot，不是收敛训练；每项任务实际曝光约 512–544 个样本。

共享多头对照按真实任务 ID 选择输出头，不以类别数量识别任务。多标签使用 sigmoid BCE，Score 同时使用有序分类头与标准化标量回归头（两个损失各 0.5 权重）。因此 Score 对照共享了双目标监督，不能解释为对纯标量回归的独立消融。候选模型使用原始 Laya 的三个类型嵌入；旧 Choice 专用 collator 的全零类型设定没有沿用。

## 数据边界

- 启动子、结构类别与同源配对采用已有来源的 train/val；剪接数据取用户提供的公开池，排除旧测试成员后按 DNA/反向互补组确定 train/dev。
- GFP 来自 [TAPE 原始数据发布](https://github.com/songlab-cal/tape)，使用 train/valid，未读取其 test JSON；Score 阈值和数值锚点仅用选中的 1,024 个训练样本拟合。
- [DeepLoc 2.0](https://services.healthtech.dtu.dk/services/DeepLoc-2.0/) 官方数据的 0/1/2 分区用于 train、3 用于 dev、4 留出不用。保留源文件的十个定位标签，包括 Plastid。采用其注释恢复口径，不能把缺失定位注释解释为湿实验否定。
- 跨任务做完全相同序列、DNA 反向互补和双序列端点连接组件隔离。旧 test 成员及其相连组件排除；train/dev 与保护集合交叉数均为零。没有运行新的全局同源聚类或基因组坐标隔离。GFP 原生变体划分本就共享亲本，不能声称蛋白家族独立。
- 完整输入按实际 Laya tokenizer 检查，最长 1,024 tokens，不截断。DeepLoc 被审计的 train/dev 候选中有 626 条输入超过预算而被排除。样本按预先固定的 ID 哈希抽取，不依据模型输出挑选。
- dev 同源配对正例 114/128；总预测正例就有 89.06% Accuracy。结构类别 dev 有一个类别零支持；Macro-F1 仍按全部七类计算。多标签部分稀有类仅有 1–3 个 dev 正例，不能用一次 pilot 作稳定的逐类结论。

## 已完成的 100 步 dev 结果

每项只评价固定 128 个开发样本，单 seed；没有独立 test、显著性结论或广泛泛化主张。Accuracy 是百分数，其他指标是原尺度，不能跨行直接平均。

| 任务 | 指标 | 常数／规则基线 | 共享评分器 | 共享多头 |
|---|---|---:|---:|---:|
| 启动子 | Accuracy ↑ | 45.31% | 77.34% | 55.47% |
| 剪接 | Accuracy ↑ | 57.03% | 57.03% | 57.03% |
| 结构类别 | Accuracy ↑ | 35.16% | 43.75% | 40.62% |
| 双蛋白同源 | AUROC ↑ | 1.0000（序列比对） | 0.9987 | 0.6754 |
| GFP 荧光 | MAE ↓ | 0.5623（训练中位数） | 0.6395 | 1.6334（标量头） |
| 多标签定位 | Micro-AUPRC ↑ | 0.2964 | 0.3019 | 0.1657 |

共享评分器的启动子/结构类别结果高于常数基线，但剪接仍是多数类预测。GFP 的 Spearman 为 -0.0951，共享多头标量头为 0.1015；两者 MAE 都未超过训练中位数基线，因此 Score 管线跑通不等于荧光预测已有效。多标签评分器的 Micro-AUPRC 仅略高于先验基线；固定 0.5 阈值下 F1 为 0，未在 dev 上事后调阈值。

同源配对 AUROC 很高，但普通全局仿射缺口比对就能在该 dev 子集达到 Accuracy/AUROC/MCC 全为 1。规则阈值只在 train 上选择。这说明当前配对子集很容易，只能提供双序列接口的工程证据，不能支持超越比对或广泛生物推理的主张。正式配对实验需要更难的来源和同源簇隔离。

共享多头在部分任务明显尚未收敛，不能把 100 步结果作为候选接口全面优越的证据。两种方法的参数初始化/池化差异仍需披露。完整的训练前后指标、支持数、常数/比对基线与运行证据见 [comparison.json](../artifacts/laya_multitask_pilot/comparison.json)。

共享评分器纯训练耗时 6.42 分钟，共享多头 2.57 分钟，峰值 allocated 显存分别 7.89/7.88 GiB。候选面板重复编码序列，成本高于一次输出十个 sigmoid 的共享多头；这些是训练成本，不是推理延迟比较。

从相同原始初始化重新开始，在同一六任务开发子集上，每个任务完整曝光三遍。共享评分器和共享多头各 576 步、有效 batch 32，单卡顺序运行；不是从 pilot checkpoint 续训。保持原学习率和任务均衡规则，不因查看 dev 结果换任务、改标签或选择最优 checkpoint。

运行时间为 2026-09-24 03:39–04:34 UTC，实际总耗时 55.54 分钟；两个进程正常退出，均跑满 576 步。每任务恰好曝光 3,072 个样本。两个 checkpoint 的 SHA-256 与记录一致，重载 dev 概率最大差均为 0，训练损失和梯度全部有限，日志未发现 OOM 或异常栈。

本地目录：`/root/autodl-tmp/jev_gene/artifacts/laya_multitask_v2/development_round1/`。`status.json` 为实时队列状态；`candidate.log` / `shared_heads.log` 为日志；最终 `comparison.json` 已自动汇总。Git 中的 [launch record](../artifacts/laya_multitask_pilot/development_round1_launch.json) 是启动快照，不是任务已完成的证明。

### 三遍曝光后的 dev 结果

仍为单 seed、每任务 128 个 dev 样本，原测试集未做新推理。表中的共享多头也已训练 576 步，并使用相同生物样本曝光预算。

| 任务 | 指标 | 简单基线 | 共享评分器 | 共享多头 |
|---|---|---:|---:|---:|
| 启动子 | Accuracy ↑ | 45.31% | 83.59% | 75.78% |
| 剪接 | Accuracy ↑ | 57.03% | 57.03% | 57.03% |
| 结构类别 | Accuracy ↑ | 35.16% | 48.44% | 42.19% |
| 双蛋白同源 | AUROC ↑ | 1.0000（序列比对） | 1.0000 | 0.9887 |
| GFP 荧光 | MAE ↓ | 0.5623（训练中位数） | 0.6242 | 0.6225（标量头） |
| 多标签定位 | Micro-AUPRC ↑ | 0.2964（训练先验） | 0.3264 | 0.2689 |

评分器相对 100 步 pilot 的启动子 Accuracy 从 77.34% 提升到 83.59%，结构类别从 43.75% 到 48.44%；本轮相对多头分别高 7.81 和 6.25 个百分点。这是当前开发子集的观察，不是跨 seed 显著性或测试集结论。

剪接 Accuracy 仍等于多数类基线；评分器 Macro-F1 从 0.2421 到 0.2754，但不能据此说该任务已经学好。GFP Score 的 Spearman 从 -0.0951 到 0.1132，训练末尾 CE 约 1.61，接近五类均匀预测的交叉熵；MAE 仍差于训练中位数，尚无有效回归优势。多标签 Micro-AUPRC 有改善，但固定 0.5 阈值的 Micro-F1 仅 0.0719，多头为 0；需要在独立 calibration 上处理阈值，不能在当前 dev 上追分。

同源配对评分器 Accuracy/AUROC 均为 1，仍与简单比对持平，不能当成核心方法优势。下一步应优先诊断剪接标签/输入及 Score 的可学习性，并为多标签增加独立校准，再决定是否扩大到 12 个任务及多 seed。可通过同预算的单任务锚点区分联合训练干扰与底座/输入表示不足；本轮尚未做这项因果区分。

纯训练耗时：评分器 37.07 分钟、多头 16.63 分钟；峰值 allocated 显存分别 7.89/7.88 GiB。完整结果及完成状态见 [round1 artifacts](../artifacts/laya_multitask_round1/)。本次检查未启动新训练或新测试集推理。
